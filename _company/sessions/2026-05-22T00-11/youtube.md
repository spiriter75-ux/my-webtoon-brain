# 작업 계획서: 네이버웹툰 API 기반 SF 웹툰 트렌드 및 독자 반응 패턴 분석

**담당 에이전트:** `data_analyst_agent`  
**수행 기간:** 24 시간 내 (실시간 데이터 수집 및 분석)  
**상대 에이전트:** `content_strategy_agent` (결과 전달)  
**최종 산출물:** `SF_Webtoon_Trend_Analysis_Report_v1.md`

---

## 1. 목표 정의 (Objective)
네이버웹툰 공식 API 를 활용하여 최근 30 일~90 일간 연재 중인 SF 장르 웹툰의 정량적/정성적 데이터를 수집·분석합니다. 이를 통해 **연재 트렌드 변화**와 **독자 반응 패턴**을 규명하고, 이를 바탕으로 `content_strategy_agent` 가 '다음 에피소드 기대감 유발 전략'을 수립할 수 있도록 명확한 인사이트와 데이터 근거를 제공합니다.

## 2. 핵심 분석 지표 (Key Metrics)
다음 4 가지 차원의 데이터를 추출하고 상관관계를 분석합니다.

### A. 연재 트렌드 (Serialization Trends)
- **출판 주기와 갯수:** SF 장르 내日均 업로드 횟수 및 주당 에피소드 평균 개수 변화 추이
- **연재 기간 분포:** 신작 vs 중반작 vs 후반작 비율 및 평균 연재 수명
- **장르 하위 분류 비중:** 사이언스 픽션, 마술적 사실주의, 하드 SF, 스페이스 오페라 등 세부 장르별 인기 변동

### B. 독자 반응 패턴 (Reader Reaction Patterns)
- **댓글 정량 분석:** 
  - 평점 (Rating) 평균 및 분포도
  - 댓글 수 (Comment Count) 의 시계열 변화
  - 긍정/부정/중립 감정 분석 (NLP 기반 키워드 추출: '끝', '다음', '빠름', '느림', '구독' 등)
- **구독 및 조회수:** 
  - 에피소드별 구독자 증가율 (Subscription Growth)
  - 조회수 급등/급락 원인 파악 (특정 에피소드에서의 반응 이상치 탐지)

### C. 콘텐츠 구성 특징 (Content Characteristics)
- **에피소드 길이:** 평균 페이지 수 및 클라이맥스 배치 패턴
- **스토리 전개 속도:** 각 에피소드당 진행되는 플롯 개수 및 클리어업/클리프행거 비율

### D. 시장 경쟁 구도 (Market Landscape)
- **톱 10 SF 웹툰 순위 변화:** 주간/월간 랭킹 변동성 분석
- **신인 작가 vs 베테랑 작가:** 성공 확률 및 독자 반응 차이 비교

## 3. 실행 단계 (Execution Steps)

### Phase 1: 데이터 수집 및 전처리 (0 ~ 4 시간)
- **API 연결 테스트:** 네이버웹툰 Open API 인증 및 엔드포인트 확인 (Webtoon List, Episode Detail, Comment, Rating 등)
- **스크립트 개발:** Python 또는 Node.js 기반으로 SF 장르 필터링 및 대상 웹툰 목록 추출 로직 구현
- **데이터 추출:** 
  - 대상: 현재 연재 중인 SF 웹툰 전체 (또는 상위 50~100 작)
  - 기간: 최근 3 개월 분기별 데이터
  - 필드: 에피소드 ID, 제목, 업로드일, 페이지 수, 조회수, 댓글 수, 평점, 태그
- **클렌징:** 중복 제거, NULL 값 처리, 날짜 형식 표준화

### Phase 2: 정량적 분석 및 시각화 (4 ~ 12 시간)
- **통계적 요약:** 평균, 중앙값, 표준편차, 분위수 계산
- **시계열 분석:** 시간 흐름에 따른 평점 및 댓글 수의 추세 (Trend) 와 계절성 (Seasonality) 확인
- **상관관계 분석:** 에피소드 길이 vs 평점, 업로드 주기 vs 구독 증가율 등 주요 변수 간 관계 규명
- **시각화 작업:**
  - 트렌드 라인차트 (연재 주기, 평점 추이)
  - 히트맵 (장르별 반응 강도)
  - 분포도 (에피소드 길이, 평점 분포)
  - 토폴로지 맵 (작가별 네트워크 또는 장르별 계층 구조)

### Phase 3: 정성적 인사이트 도출 및 보고서 초안 작성 (12 ~ 20 시간)
- **패턴 해석:** 
  - "SF 독자는 어떤 시점에 가장 활발히 댓글을 남깁니까?"
  - "평균 페이지 수가 평점에 미치는 영향은 무엇입니까?"
  - "신작 SF 웹툰의 초기 반응은 어떻게 관리될 수 있습니까?"
- **예상치 탐지:** 기존 패턴과 다른 이상적인 데이터 포인트 식별 및 그 원인 추론
- **보고서 초안 작성 (`SF_Webtoon_Trend_Analysis_Report_v1.md`):**
  - Executive Summary (최고 경영진 요약)
  - Methodology (분석 방법론)
  - Key Findings (주요 발견 사항 - 데이터 기반)
  - Trend & Pattern Insights (트렌드 및 패턴 심층 분석)
  - Limitations (분석 한계점)
  - Next Steps for Strategy (전략 수립을 위한 제안)

### Phase 4: 검토 및 전략 에이전트 전달 (20 ~ 24 시간)
- ** 자체 검토:** 데이터의 일관성 및 논리적 흐름 확인
- **전달:** 완성된 보고서 초안을 `content_strategy_agent` 에 전달 및 미팅 일정 조율
- **후속 조치:** 전략 에이전트의 질의에 대한 추가 데이터 요청 또는 보완 작업 준비

## 4. 예상 산출물 형식 (Deliverable Format)
**파일명:** `SF_Webtoon_Trend_Analysis_Report_v1.md`  
**구조:**
1. **Executive Summary:** 3 분 안에 읽을 수 있는 핵심 결론 (데이터 기반)
2. **Data Overview:** 수집된 데이터의 범위, 기간, 샘플 수
3. **Trend Analysis:** 연재 패턴, 장르 동향, 시장 구조 변화
4. **Reader Behavior:** 독자 반응 (댓글, 평점, 구독) 의 시간적·내용적 패턴
5. **Key Insights & Hypotheses:** 분석에서 도출된 핵심 인사이트 및 검증 가능한 가설
6. **Strategic Recommendations for Next Episode:** 전략 에이전트가 바로 활용할 수 있는 실행 가능한 아이디어 3 가지 (예: 클리프행거 타이밍, 에피소드 길이 최적화 등)
7. **Appendix:** 원본 데이터 샘플, 시각화 그래프 링크

## 5. 리스크 및 대응 방안 (Risks & Mitigation)
| 리스크 | 대응 방안 |
| :--- | :--- |
| API 레이트 제한 (Rate Limit) | 배치 처리 (Batch Processing) 활용, 백오프 시간 (Backoff) 로직 적용 |
| 데이터 불일치/누락 | 다중 소스 교차 검증 (Cross-validation), 명확한 NULL 처리 규칙 정의 |
| NLP 감정 분석 정확도 저하 | 도메인별 맞춤 키워드 사전 구축, 수동 샘플링 검증 포함 |
| 전략 에이전트의 구체적 요구사항 변경 | 분석 과정에서 유연하게 변수를 추가할 수 있도록 모듈화 설계 |
