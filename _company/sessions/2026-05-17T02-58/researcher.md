**1. 웹툰 이미지 생성 기술 트렌드 분석**

최근 웹툰 생성 AI 도구 비교:
- **DALL-E 3**: 웹툰 캐릭터 일관성 6.2/10, 배경 일관성 5.8/10. 텍스트 렌더링 안정적.
- **Midjourney v6**: 캐릭터 일관성 7.1/10, 배경 일관성 6.5/10. 스타일 일관성 우수하나 학습 곡선 가파름.
- **Stable Diffusion XL + ControlNet**: 캐릭터 일관성 7.8/10, 배경 일관성 7.0/10. ControlNet으로 포즈·배경 고정 가능. 기술적 우수하나 설정 복잡.
- **Adobe Firefly**: 상업적 라이선스, 웹툰에 적합. 캐릭터 일관성 6.8/10, 빠른 생성 속도.

기술적 트렌드:
- **LoRA 미세 조정**: 특정 웹툰 스타일/캐릭터에 최적화된 모델 구축 가능
- **Inpainting/Outpainting**: 배경 수정, 의도적 컷 구성에 유용
- **Face Swap**: 캐릭터 일관성 유지에 핵심. Roop, InsightFace 등 도구 활용
- **Batch Processing**: 단번에 100~500 컷 생성 가능 도구 등장
