# 💻 Webtoon AI 작화 파이프라인 및 캐릭터 일관성 제어 패턴

ComfyUI API와 AI 생성 모델을 활용하여, 스토리보드 콘티를 실제 웹툰 작화 이미지로 대량 자동 변환하고 캐릭터 디자인의 일관성을 극대화하기 위한 기술적 파이프라인 스킬셋입니다.

## 1. ComfyUI API 및 워크플로우 자동화
- **동적 파라미터 맵핑**: 프론트엔드 대시보드에서 전송된 프롬프트, 모델명, 업스케일 여부, 해상도 설정값을 ComfyUI JSON 페이로드의 지정된 노드(예: CLIPTextEncode, KSampler)에 동적으로 맵핑하여 자동 실행합니다.
- **배치 렌더링 최적화**: 여러 장의 컷을 동시 생성할 때 생기는 메모리 과부하를 막기 위해, 순차적 큐(Queue) 처리 방식을 구축하여 VRAM OOM(Out of Memory)을 사전에 차단합니다.

## 2. 캐릭터 디자인 일관성 (Consistency) 제어
- **고유 LoRA 트리거 연동**: 디자이너가 설정한 캐릭터 바이블에 맞춰 지정된 LoRA 모델을 적용하고, 최적의 가중치(보통 0.6 ~ 0.8)를 노드에 자동 주입합니다.
- **ControlNet 포즈 제어 (OpenPose/Canny)**: 콘티의 거친 펜선이나 포즈 스케치를 뼈대 데이터(OpenPose) 또는 실선 데이터(Canny)로 추출한 뒤, ControlNet을 통해 인물의 포즈와 앵글이 원작자의 기획안과 100% 일치하도록 보정합니다.

## 3. 고해상도 웹툰 업스케일링 및 후처리
- **Ultimate SD Upscale**: 생성 완료된 러프 이미지를 모바일 화면 가독성에 맞게 선명하게 보정하기 위해, 타일 기반 업스케일 노드를 조합하여 디테일을 뭉개지 않고 2배 크기로 확장합니다.
