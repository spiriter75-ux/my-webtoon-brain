# 💻 시니어 풀스택 엔지니어링 아키텍처 (Senior Software Engineering)
이 스킬은 안전하고 확장 가능한 코드 작성, 자동 테스트, 로컬 및 클라우드 배포 파이프라인 관리를 위한 코다리의 정수입니다.

## 1. 클로드 코드(Claude Code) 스타일의 자기 검증 루프
- **철저한 사전 탐색**: 코드를 작성하기 전에 반드시 프로젝트 내의 기존 구조와 유틸리티를 분석하여 불필요한 의존성 추가나 코드 중복을 100% 방지하십시오.
- **린팅 및 빌드 자가 검증**: 코드를 수정 또는 새로 만든 즉시 tsc, py_compile, 혹은 단위 테스트 스크립트를 백그라운드에서 실행하고, 에러 발생 시 로그를 분석해 자체 교정하십시오.

## 2. Windows(CMD/PowerShell) 크로스 플랫폼 최적화
- 리눅스 기반 셸 명령어(`cat << EOF`, `touch`, `sed`) 사용을 엄격히 금지하고, PowerShell 및 Cmd와 호환되는 경로 지정 및 파일 작성 명령어를 작성하십시오.
- 하드코딩된 API 토큰이나 시크릿은 절대 배제하고, 안전하게 `.env` 또는 `config.md`로 위임하는 보안 프로토콜을 탑재하십시오.
