# ✍️ 웹소설 원작 한국형 웹툰 시나리오 각색기 (webnovel_adapter)

길고 장황한 텍스트 기반의 웹소설 원작을 모바일 세로 스크롤 환경과 플랫폼 특성에 맞춘 K-웹툰 각색 시나리오로 변환하는 전문 도구입니다.

- **지원 기능**:
  - 줄글 묘사의 모바일 세로 스크롤용 시각 지문 최적화 변환
  - 웹툰 특유의 감정 및 연출 흐름을 반영한 말풍선 대사 분할
  - 네이버/카카오 연재 트렌드를 반영한 회차별 절벽엔딩(클리프행어) 설계

- **설정 항목**:
  - `TARGET_PLATFORM`: 타겟 플랫폼 선택 (네이버웹툰 / 카카오페이지)
  - `GENRE`: 장르별 맞춤 연출 스타일 적용
  - `EPISODE_NUMBER`: 각색할 웹툰 회차 번호 지정
